# Mint-Chat-manager
Бот ВКонтакте на C# с использованием Long Poll API.

## Запуск

Нужен .NET 10 SDK и токен сообщества с доступом к сообщениям. ID сообщества по умолчанию: `232664735`.

В настройках сообщества включите сообщения, разрешите сообществу получать сообщения в беседах, включите Long Poll API и отметьте событие `message_new`. Для личных сообщений пользователь должен разрешить сообщения от сообщества.

Скопируйте шаблон настроек и укажите токен сообщества в `.env`:

```sh
cp env.example .env
# укажите токен сообщества и сильный пароль PostgreSQL в .env
docker compose up -d postgres
dotnet run
```

Файл `.env` игнорируется Git. Также можно передать токен через переменную окружения:

```powershell
$env:VK_ACCESS_TOKEN = "токен сообщества"
dotnet run
```

Переменные окружения имеют приоритет над значениями из `.env`. При необходимости ID сообщества можно переопределить через `VK_GROUP_ID`. Ошибки Long Poll и отправки ответов выводятся в консоль.

Добавляйте новые команды в папку `commands` и регистрируйте их в `Program.cs`.
PostgreSQL запускается локально через Docker Compose. Бот автоматически создаёт таблицу `user_profiles` и сохраняет ID автора сообщения, число обработанных сообщений и JSONB-настройки отдельно для каждого пользователя, в том числе в беседах. Команда `/профиль` показывает данные пользователя. Данные базы хранятся в Docker volume `postgres_data`; база доступна только с локального компьютера.

Команды: `/ping`, `/стата`, `/аптайм`, `/ресурсы`, `/help`, `/время`, `/id`, `/профиль`, `/ии вопрос`, `/sql SELECT ...` и `/echo текст`. Команда `/ии` отправляет запрос в локальный Ollama API. Адрес задаётся через `OLLAMA_BASE_URL` (по умолчанию `http://localhost:11434/`), модель — через `OLLAMA_MODEL` (по умолчанию `qwen2.5:7b`); модель должна быть установлена и Ollama должна быть запущена. `/sql` разрешена только пользователям из `BOT_ADMIN_IDS` (по умолчанию ID `778382713`), принимает один `SELECT`/`WITH` в read-only транзакции и ограничена таймаутом 3 секунды, 15 строками и 8 столбцами. Сообщения обрабатываются четырьмя параллельными обработчиками через ограниченную очередь из 64 сообщений; события Long Poll преобразуются в компактные записи без копирования полного JSON.
Команда `/ping` отвечает `pong`, показывает время обработки команды в миллисекундах, занятую и свободную системную память, а также среднюю загрузку CPU ботом с момента запуска. Показатели системной памяти поддерживаются на Linux и Windows.
Команда `/аптайм` показывает время работы, а `/ресурсы` — рабочий набор и управляемую кучу процесса бота.
Команда `/стата` сразу отправляет текстовую статистику, затем прикрепляет сгенерированную в памяти PNG-карточку и загружает её в VK без внешних графических зависимостей. PNG кодируется потоком с табличным CRC, а карточка оформлена градиентным фоном и цветными информационными блоками.
Для каждой группы одновременно разрешён только один экземпляр бота: дополнительный процесс завершится с сообщением об уже работающем экземпляре.
